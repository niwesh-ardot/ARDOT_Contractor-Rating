# ARDOT contractor performance briefing

This static website accompanies TRBAM-27-04931, “Preserving Low-Bid Integrity While Measuring Contractor Performance in State DOTs.” It is prepared for a discussion with Jesse Jones, ARDOT Chief Engineer.

## Open or present the briefing

Unzip the website and open `index.html` in Edge, Chrome, Firefox or Safari. The site needs no installation or build step. **Present** opens a chapter-by-chapter view. Use **Previous** and **Next** or the left and right arrow keys. Press **Esc** to return to the full briefing. Within the peer comparison, arrow keys move between agencies. The source links open the published documents and require internet access.

For a live discussion, start with the bid tab and let Jesse call the award before opening the answer. In the evidence section, open the two records separately and ask what ARDOT can attribute to each contractor. Then compare Arkansas and Washington in the research section before moving to the validation decision.

## Publish with GitHub Pages

1. Add the extracted files, including `index.html`, to the root of your GitHub repository's `main` branch.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save. GitHub lists the site URL on the Pages settings screen after deployment.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
